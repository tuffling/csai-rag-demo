# ⚠️ These documents are FAKE

Everything in this folder was **made up** for a classroom demo about RAG. It is **not real news** and has nothing to do with Taco Bell. None of these products, programs, prices or stores exist.

Why use a real company name? A chatbot already "knows" a lot about Taco Bell from its training data. These made-up documents are "news" it has never seen. That lets us compare:

- **Without RAG:** the chatbot answers from what it remembers (or admits it has never heard of this).
- **With RAG:** we paste these documents into the prompt, and the chatbot repeats them confidently, **even though they're fake**.

That last part is the real lesson: a RAG system is only as trustworthy as the documents you feed it.
